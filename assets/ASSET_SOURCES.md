# Asset sources

- `branding/shortcut-mascot.png` and `branding/shortcut-mascot-turnaround.png` were generated for the shortcut character design requested by the project owner.
- `branding/shortcut.ico` is a multi-size Windows icon converted from `shortcut-mascot.png` for the application and installer.
- The 64 PNG files in `icons/shortcut-moe-v1/icons/` were generated for shortcut category and system-entry icons requested by the project owner.
- No upstream application icon or screenshot is included in this asset set.

To replace an icon, retain its filename and update `icons/shortcut-moe-v1/manifest.json` when the category mapping changes.
