# 设置与验证说明

当前实现位于 `shortcut_app/`，根目录 `shortcut.py` 仅负责启动。配置使用 `%USERPROFILE%\.shortcut\config.json`；现有配置继续使用，历史品牌兼容标识已移除。

## 交互规则

| 场景 | 行为 |
| --- | --- |
| 从偏好设置进入分类管理 | 分类管理归属于偏好设置，使用窗口模态；关闭前偏好设置不接受输入。再次点击设置入口会聚焦分类管理。 |
| 应用与窗口图标 | 应用、偏好设置、分类管理和托盘共用 `assets/branding/shortcut.ico`；Windows 应用标识统一为 `vv11x.shortcut`。图标缺失会直接报错。 |
| 显示模式 | 快捷栏与桌面分类盒互斥，主题和分类内容共用；与当前模式无关的设置禁用并注明用途。 |
| 桌面图标 | 按所选模式收纳；隐藏界面或退出恢复原生图标，重新显示继续应用原选择。原文件不移动。 |
| 桌面分类盒 | 默认 4×4 预览，完整分类数量不限；支持拖动位置、分页和虚拟归类。保留原生回收站入口。 |
| 分类与文件 | 分类编辑先修改草稿，保存才生效；文件复制、剪切、回收、压缩和外壳菜单操作原入口。 |
| 偏好设置保存 | 六页偏好设置即时保存，底部明确提示；再次打开及从托盘修改后同步控件，不产生额外保存。 |
| 分类页导航 | 管理与立即整理位于图标列表之前，更换或恢复图标后保留滚动位置；预览按屏幕像素密度绘制。 |
| 分类封面 | 管理窗口显示当前自定义图片；选择内置封面在保存后替换自定义图片，取消保留原设置。删除分类时同步清理其图片引用。 |
| 规则编辑 | 不同规则类型保留各自输入；切换分类不丢失空规则草稿，保存前提示处理空名称与空规则。分类和恢复排除入口一次提交。 |
| 指定文件匹配 | 文件选择器保留完整路径列表，文件名中的中英文逗号不再拆分路径；复合扩展名可匹配文件及快捷方式目标。 |
| 保存失败 | 原始写入异常向上传递，管理窗口提示失败并保留草稿；分类、封面与分隔符不会发布未保存的修改。 |
| 添加到分类 | 分类选择项显示序号以区分同名分类；创建首个分类后继续使用已选择的文件。 |
| 右键隐藏 | 快捷栏与托盘的隐藏入口统一停止收纳并恢复 Windows 原生图标。 |
| 高 DPI | 保留分数缩放，图标按实际屏幕像素绘制并对齐像素边界；品牌入口保留 512 像素源图。 |
| 资源和错误 | 原生组件或图标资源缺失时暴露具体错误；桌面宿主故障保留用户模式并报告原因。 |

## 自动化检查

```powershell
python -B -m unittest discover -s tests -p 'test_*.py'
.\tests\run_native_tests.ps1
```

Python 测试覆盖设置控件、窗口所有权和模态、图标资源、当前配置读写、分类规则、面板操作、桌面模式、搜索与高 DPI 绘制。原生测试覆盖 6 个看门狗生命周期场景及 Shell 菜单的构建、取消、校验和消息转发。

## Windows 实机检查

在当前程序正常退出后显式执行；测试会临时显示窗口或收纳原生桌面图标，结束后恢复。

```powershell
python -B tests/manual/smoke_dialogs.py
python -B tests/manual/smoke_search.py
python -B tests/manual/smoke_transitions.py
python -B tests/manual/smoke_packaged.py
```

界面及桌面回归使用隔离配置；打包检查默认运行工程外的 `F:\shortcut-output\dist\shortcut\shortcut.exe`，也可通过 `SHORTCUT_EXE` 指定，并使用独立测试用户配置目录。搜索检查覆盖四边停靠、按钮与可见主栏的距离、真实点击、展开及 Esc 收回。临时图片、配置和诊断写入系统临时目录中的 `shortcut-validation/`，不进入源码。

已在本机验证窗口所有权、模态输入、原生窗口图标、桌面挂载、图标收纳／恢复、面板过渡，以及打包程序的启动／退出。多屏热插拔、完整 Explorer 重启和真实开机登录仍需独立实机覆盖。
